# Job Listing Portal — Task 1 (Authentication Backend)

##  Overview

This module implements the **User Authentication system** for the Job Listing Portal project.

It allows job seekers and employers to securely register and log in using JWT-based authentication with encrypted password storage.

This backend follows a scalable, production-style architecture.

---

##  Features

- User registration
- Secure password hashing using bcrypt
- JWT-based login authentication
- Role-based user system (job seeker / employer)
- MongoDB database integration
- Environment-based configuration
- Modular backend architecture

---

## Tech Stack

- Node.js
- Express.js
- MongoDB + Mongoose
- bcryptjs
- JSON Web Token (JWT)
- dotenv
